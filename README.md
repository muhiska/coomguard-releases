# CoomGuard releases

Release builds of CoomGuard, the on-device screen guard made for the
members of THE CUM UP. It watches the screen, blocks explicit content with
a detector that runs on the phone or the computer, and never uploads
anything.

The builds live here so the apps can check for updates. The source is kept
in a private repository. CoomGuard is free software under the AGPL-3.0 and
bundles NudeNet (AGPL-3.0): if you received a build and want the source,
ask the staff in the Discord: https://discord.gg/a6W2P2nCCD

## Install on Android

1. Download the newest build from the download page,
   https://muhiska.github.io/coomguard-releases/ (the same file as the
   release asset, served plainly, which phone browsers handle better), and
   open it. Android warns that the app is not from the store; allow it.
2. Android 13 and newer: Settings → Apps → CoomGuard → ⋮ → Allow
   restricted settings. Then in the app tap Enable and turn on CoomGuard
   under Accessibility.
3. Updates: the app checks here on start and offers newer builds itself.

`coomguard.json` on each release is the manifest the apps read.
